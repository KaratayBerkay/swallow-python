The following exceptions are used as warning categories; see the
[Warning Categories](https://docs.python.org/3.15/library/warnings.html#warning-categories) documentation for more details.

- [`Warning`](Warning/README.md) — Base class for warning categories.
- [`UserWarning`](UserWarning/README.md) — Base class for warnings generated by user code.
- [`DeprecationWarning`](DeprecationWarning/README.md) — Base class for warnings about deprecated features when those warnings are intended for other Python developers.
- [`PendingDeprecationWarning`](PendingDeprecationWarning/README.md) — Base class for warnings about features which are obsolete and expected to be deprecated in the future, but are not deprecated at the moment.
- [`SyntaxWarning`](SyntaxWarning/README.md) — Base class for warnings about dubious syntax.
- [`RuntimeWarning`](RuntimeWarning/README.md) — Base class for warnings about dubious runtime behavior.
- [`FutureWarning`](FutureWarning/README.md) — Base class for warnings about deprecated features when those warnings are intended for end users of applications that are written in Python.
- [`ImportWarning`](ImportWarning/README.md) — Base class for warnings about probable mistakes in module imports.
- [`UnicodeWarning`](UnicodeWarning/README.md) — Base class for warnings related to Unicode.
- [`EncodingWarning`](EncodingWarning/README.md) — Base class for warnings related to encodings.
- [`BytesWarning`](BytesWarning/README.md) — Base class for warnings related to bytes and bytearray.
- [`ResourceWarning`](ResourceWarning/README.md) — Base class for warnings related to resource usage.
