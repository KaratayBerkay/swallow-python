#### Tek görev

Verilen olay: Bütün warning kategorilerini kapsaması gereken ortak taban. Kategori seçimini gerekçelendir; bunu doğrudan programı durduran hata ile karıştırma. Bu sayfada varsayılan görünürlük bilgisi varsa, uyarının görülmemesinin hiç üretilmediğini kanıtlayıp kanıtlamadığını açıkla.

#### Geçiş ölçütleri

- [ ] Warning uygun kategori olarak kaynakta tarif edilen hedef/kapsama bağlanmıştır.
- [ ] Yalnız burada belirtilen filtre bilgisi kullanılmıştır; belirtilmeyen varsayılan davranış ezberden uydurulmamıştır.
