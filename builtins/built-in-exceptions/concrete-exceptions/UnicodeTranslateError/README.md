## `UnicodeTranslateError`

```
UnicodeTranslateError
```

Raised when a Unicode-related error occurs during translating.  It is a subclass
of [UnicodeError](../UnicodeError/README.md).

#### Tek görev

Verilen olay: Unicode dönüştürme işleminin ilgili hata bildirmesi. Beklenen hata türünü veya normal sonucu çıkar. Sistem olayıysa yalnız yazılı teşhis yap; gerçek arıza üretme. Basit veri işlemi ise küçük yerel örnekle doğrula. Bu türün neden uygun olduğunu, yakın ama farklı bir durumdan nasıl ayrıldığını açıkla.
