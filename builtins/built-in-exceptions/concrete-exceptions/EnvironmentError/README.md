## `EnvironmentError`

```
EnvironmentError
```

Python 3.3 ve sonrasında bu ad OSError için geriye uyumluluk takma adıdır. Ayrı bir hata ailesi değildir.

**Ortak kontrol:** Önce [asıl anlatım ve örneği](../OSError/README.md) oku; ardından [b:4.4.15 bölüm görevini](../OSError/README.md#bölüm-görevi) çöz. Aynı davranış için ikinci çözüm istenmez.
