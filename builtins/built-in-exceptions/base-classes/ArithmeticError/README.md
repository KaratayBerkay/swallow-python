## `ArithmeticError`

```
ArithmeticError
```

The base class for those built-in exceptions that are raised for various
arithmetic errors: [OverflowError](../../concrete-exceptions/OverflowError/README.md), [ZeroDivisionError](../../concrete-exceptions/ZeroDivisionError/README.md),
[FloatingPointError](../../concrete-exceptions/FloatingPointError/README.md).
