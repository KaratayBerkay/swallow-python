## `definition.__type_params__`

```
definition.__type_params__
```

The [type parameters](https://docs.python.org/3.15/reference/compound_stmts.html#type-params) of generic classes, functions,
and [type aliases](https://docs.python.org/3.15/library/typing.html#type-aliases). For classes and functions that
are not generic, this will be an empty tuple.

> *Added in version 3.12.*
