# Görev b:2.4.6: int.is_integer sınırını göster

## Önce

[b:2.4](../README.md) ve bu sayfanın açıklama/örnekleri.

Sürüm: Python 3.12 veya üzeri. Daha eski yorumlayıcıda yalnız bu sürüme bağlı kısmı gerekçeli yazılı iz ile çözebilirsin; çalıştırma kanıtını bekleyen olarak kaydet.

## Tek görev

`(0).is_integer()` ve `(-7).is_integer()` sonuçlarını çıkar. Bunun int türüyle çalışan, float.is_integer uyumunu kolaylaştıran bir yöntem olmasını açıkla.

## Geçiş ölçütleri

- [ ] İki sonuç True; int üzerinde kesir veya sonsuz değer aranmaz.
