# Görev b:2.11.26: Keyfi seçim sınırını koru

## Önce

[b:2.11](../README.md) ve bu sayfanın açıklama/örnekleri.

## Tek görev

`s={1,2,3}` üzerinde pop çağır; dönen değerin önceki kümeye ait ve artık kümede olmadığını doğrula. Kalan iki öğeyi de çıkar. Sonraki çağrıyı yakala.

## Geçiş ölçütleri

- [ ] Belirli bir ilk değer veya sıra dayatılmadan üç öğe tam birer kez çıkmıştır.
- [ ] Boş kümede KeyError; pop dönüşü çıkarılan öğedir.
