# Görev b:2.11.25: discard ile üyeliği güncelle

## Önce

[b:2.11](../README.md) ve bu sayfanın açıklama/örnekleri.

## Tek görev

`s={1,2}; diger=s` ile başla. İlk `s.discard(1)` çağrısının dönüşünü ve iki adın üyelerini kaydet. Ardından aynı s üzerinde `s.discard(9)` çağır; sonucu veya hata türünü göster.

## Geçiş ölçütleri

- [ ] İlk üyeler `{2}`, ilk dönüş None; küme sırasına dayalı beklenti yok.
- [ ] Eksik öğe hata üretmez.
- [ ] Diger aynı kümenin güncel üyelerini görür.
