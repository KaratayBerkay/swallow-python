# Görev b:2.11.21: update ile üyeliği güncelle

## Önce

[b:2.11](../README.md) ve bu sayfanın açıklama/örnekleri.

## Tek görev

`s={1,2}; diger=s` ile başla. İlk `s.update({2,3})` çağrısının dönüşünü ve iki adın üyelerini kaydet. Ardından aynı s üzerinde `s.update([3,4])` çağır; sonucu veya hata türünü göster.

## Geçiş ölçütleri

- [ ] İlk üyeler `{1,2,3}`, ilk dönüş None; küme sırasına dayalı beklenti yok.
- [ ] Birleşim yerinde uygulanır; tekrarlar çoğalmaz.
- [ ] Diger aynı kümenin güncel üyelerini görür.
