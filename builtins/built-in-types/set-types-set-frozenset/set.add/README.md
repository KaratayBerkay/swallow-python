## `set.add`

```
set.add(elem, /)
```

Add element *elem* to the set.

<!-- learning-task:start -->
### Bölüm görevi

**Görev b:2.11.2: add ile üyeliği güncelle**

#### Önce

[b:2.11](../README.md) ve bu sayfanın açıklama/örnekleri.

#### Tek görev

`s={1,2}; diger=s` ile başla. İlk `s.add(3)` çağrısının dönüşünü ve iki adın üyelerini kaydet. Ardından aynı s üzerinde `s.add(3)` çağır; sonucu veya hata türünü göster.

#### Geçiş ölçütleri

- [ ] İlk üyeler `{1,2,3}`, ilk dönüş None; küme sırasına dayalı beklenti yok.
- [ ] Aynı öğeyi yeniden eklemek çoğaltmaz.
- [ ] Diger aynı kümenin güncel üyelerini görür.
