# Görev b:2.11.27: clear ile üyeliği güncelle

## Önce

[b:2.11](../README.md) ve bu sayfanın açıklama/örnekleri.

## Tek görev

`s={1,2}; diger=s` ile başla. İlk `s.clear()` çağrısının dönüşünü ve iki adın üyelerini kaydet. Ardından aynı s üzerinde `s.clear()` çağır; sonucu veya hata türünü göster.

## Geçiş ölçütleri

- [ ] İlk üyeler `set()`, ilk dönüş None; küme sırasına dayalı beklenti yok.
- [ ] Boş kümede tekrar çağrı geçerlidir.
- [ ] Diger aynı kümenin güncel üyelerini görür.
