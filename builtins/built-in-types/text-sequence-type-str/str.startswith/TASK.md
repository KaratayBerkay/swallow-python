## Tek görev

Aşağıdaki denemeleri ayrı ayrı incele. Sonuç veya hata türünü önce çıkar, sonra doğrula; tuple seçenekleriyle başlangıç dilimini ayır

```python
"ad.py".startswith(("x","ad"))
"xxad".startswith("ad",2)
"abc".startswith("z")
```
