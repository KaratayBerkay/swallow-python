## Tek görev

Aşağıdaki denemeleri ayrı ayrı incele. Sonuç veya hata türünü önce çıkar, sonra doğrula; sağdaki eşleşmenin özgün indeksi döner; bulunamazsa -1

```python
"ababa".rfind("ba",0,4)
"abc".rfind("x")
```
