## Tek görev

Aşağıdaki denemeleri ayrı ayrı incele. Sonuç veya hata türünü önce çıkar, sonra doğrula; chars tek bir son ek değil karakter kümesidir

```python
"abXabba".rstrip("ab")
"abXba".rstrip("ab")
```
