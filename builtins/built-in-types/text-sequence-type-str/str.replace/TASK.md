## Tek görev

Aşağıdaki denemeleri ayrı ayrı incele. Sonuç veya hata türünü önce çıkar, sonra doğrula; count sınırı ve özgün metnin korunmasını açıkla

```python
"aaaa".replace("aa","x",1)
"abc".replace("z","x")
"abc".replace("a","x",0)
```
