## Tek görev

Aşağıdaki denemeleri ayrı ayrı incele. Sonuç veya hata türünü önce çıkar, sonra doğrula; tuple seçenekleri ve dilim sınırları son ek denetimini belirler

```python
"a.txt".endswith((".py",".txt"))
"abXY".endswith("b",0,2)
"abc".endswith("z")
```
