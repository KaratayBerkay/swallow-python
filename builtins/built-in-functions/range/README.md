## `range()`

```
range(stop, /)
range(start, stop, step=1, /)
```

Rather than being a function, range is actually an immutable
sequence type, as documented in [Ranges](https://docs.python.org/3.15/builtins/stdtypes.html#typesseq-range) and [Sequence Types — list, tuple, range](https://docs.python.org/3.15/builtins/stdtypes.html#typesseq).
