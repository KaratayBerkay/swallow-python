## `str()`

```
str(*, encoding='utf-8', errors='strict')
str(object)
str(object, encoding, errors='strict')
str(object, *, errors)
```

Return a str version of *object*.  See `str()` for details.

`str` is the built-in string [class](https://docs.python.org/3.15/glossary.html#term-class).  For general information
about strings, see [Text Sequence Type — str](https://docs.python.org/3.15/builtins/stdtypes.html#textseq).
