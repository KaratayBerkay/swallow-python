## `tuple()`

```
tuple(iterable=(), /)
```

Rather than being a function, tuple is actually an immutable
sequence type, as documented in [Tuples](https://docs.python.org/3.15/builtins/stdtypes.html#typesseq-tuple) and [Sequence Types — list, tuple, range](https://docs.python.org/3.15/builtins/stdtypes.html#typesseq).
