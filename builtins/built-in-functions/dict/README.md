## `dict()`

```
dict(**kwargs)
dict(mapping, /, **kwargs)
dict(iterable, /, **kwargs)
```

Create a new dictionary.  The dict object is the dictionary class.
See also [Mapping types — dict, frozendict](https://docs.python.org/3.15/builtins/stdtypes.html#typesmapping) for documentation about this class.

For other containers see the built-in [frozendict](../frozendict/README.md), [list](../list/README.md),
[set](../set/README.md), and [tuple](../tuple/README.md) classes, as well as the [collections](https://docs.python.org/3.15/library/collections.html#module-collections) module.

**Ortak kontrol:** Önce [asıl anlatım ve örneği](../../built-in-types/mapping-types-dict-frozendict/dict/README.md) oku; ardından [b:2.12.2 bölüm görevini](../../built-in-types/mapping-types-dict-frozendict/dict/README.md#bölüm-görevi) çöz. Aynı davranış için ikinci çözüm istenmez.
