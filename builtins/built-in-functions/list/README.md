## `list()`

```
list(iterable=(), /)
```

Rather than being a function, list is actually a mutable
sequence type, as documented in [Lists](https://docs.python.org/3.15/builtins/stdtypes.html#typesseq-list) and [Sequence Types — list, tuple, range](https://docs.python.org/3.15/builtins/stdtypes.html#typesseq).
