## Tek görev

Aşağıdaki denemeleri ayrı ayrı incele. Sonuç veya hata türünü önce çıkar, sonra doğrula; boş iterable ile herhangi bir doğru öğe bulunmasını ayır.

```python
any([])
any([0,"",3])
```
