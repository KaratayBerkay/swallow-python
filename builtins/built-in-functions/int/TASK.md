## Tek görev

Aşağıdaki denemeleri ayrı ayrı incele. Sonuç veya hata türünü önce çıkar, sonra doğrula; metni tabana göre yorumlama ile floatı sıfıra doğru kesmeyi ayır.

```python
int("101",2)
int(-3.9)
int("1.2")
```
