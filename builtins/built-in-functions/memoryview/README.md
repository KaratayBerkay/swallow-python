## `memoryview()`

```
memoryview(object)
```

Return a "memory view" object created from the given argument.  See
[Memory Views](https://docs.python.org/3.15/builtins/stdtypes.html#typememoryview) for more information.

Aynı davranış için ikinci çözüm istenmez.
