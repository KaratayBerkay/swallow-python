# Görev 6.4.2: Göreli yolu paket ağacında çöz

**Odak:** Tek/çift nokta ile geçerli paket ve üst paket, mutlak yol karşılığı.

## Önce

- Bu bölümün [anlatımını ve içindeki örnekleri](README.md) tamamla.
- Ön bilgi: [t:6.4.1](../6.4.1-importing-from-a-package/README.md).

## Tek görev

1. README içindeki sound.effects.surround konumunu başlangıç kabul et. from . import echo, from .. import formats, from ..filters import equalizer satırlarının her birini tam mutlak import yoluna çevir; ağaç üstünde hangi seviyeye çıktığını göster.

2. Aynı dosyayı tek başına ana betik gibi çalıştırma ile paket bağlamında içe aktarma farkını açıklayan kısa bir not yaz.

## Geçiş ölçütleri

- [ ] Hedefler sound.effects.echo, sound.formats ve sound.filters.equalizer.
- [ ] Noktalar çalışma klasörüne göre değil paket adına göre çözülmüş.
- [ ] Tek başına betikte paket bağlamının bulunmaması açıklanmış; göreli yolu dosya sistemi yolu sanan çözüm yok.
