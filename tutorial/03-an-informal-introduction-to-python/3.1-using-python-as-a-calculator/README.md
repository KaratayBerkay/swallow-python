#### Tek görev

1. Bir REPL çalışmasında unit_price=12.5, quantity=3 ve names=["pear", "apple"] kur.

2. Toplam ve 4 ürüne tamamlamak için eksik sayıyı hesapla. names için ortak ad ve dilim kopyası oluştur; ortak ad üzerinden "fig" ekle, kopyada ilk metnin ilk karakterini değiştirerek yeni metin ata.

3. İlk/son öğeyi, dilimlerin birleşimini ve kaynak verinin son halini göster.

4. Kodda döngü veya fonksiyon kullanman gerekmiyor.
